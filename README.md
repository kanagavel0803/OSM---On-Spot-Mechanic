# OSM - On Spot Mechanic 🚗🔧

OSM (On Spot Mechanic) is a Flutter-based mobile application that helps users find nearby mechanics in case of vehicle breakdowns. 
It integrates **Google Map API, Firebase authentication, location tracking, and real-time booking** features.


# Customer Features 👤
✔️ Easy Registration 
✔️ Report Vehicle Issues – Specify location, describe the problem, and add vehicle details. <br>
✔️ Live Location Tracking – GPS-based tracking for accurate service requests. <br>
✔️ Quick Mechanic Allocation – Requests are broadcasted to nearby available mechanics. <br>

# Mechanic & Garage Features 🛠️
✔️ Mechanic Availability System – Only available mechanics can accept requests. <br>
✔️ Order Assignment – Efficient allocation ensures only one mechanic gets the request. <br>
✔️ Notification System – Nearby garages are informed when an order is taken. <br>
